# Ice Legends

Хоккейная карточная игра в стиле FC Mobile на **Godot 4.3** (GDScript). Собирайте игроков из паков, составляйте звено, играйте матчи в реальном времени и прокачивайте команду.

## Запуск
1. Откройте папку проекта в Godot 4.3+ (файл `project.godot`).
2. Нажмите F5. Главная сцена — `main.tscn`.

## Возможности
- Карточки: Бронза / Серебро / Золото / Лёд; позиции — крайний, центр, защитник, вратарь
- Состав: 2 крайних, центр, 2 защитника, вратарь + автосостав
- Паки за монеты, тренировка (+1 до +8), продажа карт
- Сезон из 12 соперников с растущим рейтингом, затем новый круг сложнее
- Матч: 3 периода по 45 с, овертайм, буллиты; джойстик, бросок (угол ворот задаёт джойстик), пас, отбор
- Прогресс сохраняется автоматически (`user://ice_legends.json`)

## Управление
- Телефон: левая половина экрана — джойстик; кнопки БРОСОК / ПАС / ОТБОР справа
- ПК: WASD или стрелки, `Пробел` — бросок, `E` — пас, `Q` — отбор, `Esc` — пауза

## Структура
- `scripts/main.gd` — меню, состав, магазин, коллекция
- `scripts/match_view.gd` — отрисовка матча и управление
- `scripts/match_sim.gd` — физика и ИИ матча (без отрисовки)
- `scripts/game_data.gd` — карточки, монеты, сохранение

## APK для Android
Workflow `.github/workflows/android.yml` собирает отладочный APK при каждом пуше в `main` (Actions → Build Android APK → Artifacts → `IceLegends-apk`).
